# Predicting House Prices in New York

This project investigates which property and neighbourhood features best predict residential house prices in New York. Using a dataset of 1,734 housing sales, we cleaned the data, performed exploratory analysis, built predictive models, and interpreted results through a structured analytical report.

## Key Features

- Cleaned and pre-processed real-world housing sales data

- Performed exploratory data analysis and correlation assessment

- Built and compared:

  - Multiple Linear Regression (interpretable model)

  - Random Forest (non-linear model comparison)

- Applied stepwise AIC and BIC-based model selection

- Conducted cross-validation to assess model generalisability

- Produced diagnostic checks for regression assumptions

- Interpreted model coefficients to explain real-world price drivers

## Tools Used

- R / Python for data analysis and modelling

- Statistical modelling libraries

- Reproducible reporting (Quarto / LaTeX / Jupyter)

## Key Findings

- Living area and land value were the strongest predictors of house prices

- The final regression model explained ~64% of price variation

- Random forest captured mild non-linear effects but was less interpretable

- Delivered a clear written report translating statistical outputs into practical insights

## Outcome

A complete analytical workflow from raw data to validated predictive models and a professional research-style report.
